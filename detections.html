Encoded PowerShell Command

Identifies PowerShell commands executed through Base64 encoded arguments.

Rule ID 100003
MITRE T1059.001 - PowerShell
Detection Logic -EncodedCommand
HIGH | LEVEL 12

Hidden PowerShell Execution

Flags PowerShell instances initiated with hidden window arguments, a standard tactic used by attackers to hide background command execution from users.

Rule ID 100004
MITRE T1059.001 - PowerShell
Detection Logic -WindowStyle Hidden
