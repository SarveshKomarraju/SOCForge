SECURITY STACK

Technologies Used

Wazuh SIEM/XDR

Serves as the analytical brain of the lab. It ingests unstructured event logs forwarded by agents, passes them through customized XML decoders, and checks them against rulesets to identify active compromises.

System Monitor (Sysmon)

Provides deep-visibility host monitoring. Configured with a customized modular XML configuration to filter noisy background processes while capturing high-fidelity Event IDs (e.g., ID 1 for Process Creation, ID 3 for Network Connections).

MITRE ATT&CK Framework

Used to operationalize incoming alerts. By tagging custom rules with ATT&CK technique IDs (such as T1059 for Command and Scripting Interpreter), alerts are contextually aligned with actual real-world threat actors.
